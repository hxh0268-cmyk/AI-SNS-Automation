## 1. Purpose

This directory holds durable, official-source Contract-Fit Research records and the unified Provider re-evaluation matrix for Bounded Text Publishing MVP (Branch A — pure text-only).

## 2. Scope

### In scope

- Official primary-source research summaries (Instagram, Threads, X)
- Normalized C1–C20 comparison matrix
- Official source register
- Selection outcome documentation handoff

### Out of scope

- Provider Authorization
- Concrete endpoint allowlist approval
- Credentials / OAuth / API execution
- Catalog registration
- Runtime / adapter implementation
- P2B+ / External IO enablement

## 3. Official-source-only rule

Final evidence domains are limited to official Provider documentation (Meta / X developer docs and terms). Search results, blogs, Stack Overflow, unofficial mirrors, preview hosts, and AI summaries are **not** final evidence.

## 7. Source-register role

Records canonical URLs, retrieval dates, applicability, confidence, conflicts, and review triggers. No long verbatim dumps. No Console rates claimed as viewed.

## 8. Matrix role

Normalizes Research ratings without rewriting them. Records rule-first selection rationale, entry conditions, and Recommended ≠ Authorized.

## 9. Retrieval-date policy

Each research record states a retrieval-date baseline. Pricing and product pages are **time-bound evidence**, not permanent truth. Material change requires bounded re-evaluation; External IO remains off until resolved.

## 10. Evidence confidence

Ratings may share a label but differ in confidence (High / Medium / Low). Unknown/Low confidence must not be promoted to Medium/Strong.

## 11. Conflict handling

Official conflicts are recorded with both sources; no averaging of prices; no picking cheaper/safer without resolution rules from Research.

## 12. Re-evaluation triggers

See matrix and Provider Selection Record. Examples: X public/Console pricing change, URL surcharge change, OAuth/scope change, Threads public pricing publication, Instagram native text API, MVP boundary change.
